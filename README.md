## 原生 IP、住宅 IP、双 ISP，WePC 的标签怎么读

原生 IP 指 IP 归属地和服务器所在地一致，没有经过转发伪装。住宅 IP（家宽 IP）指这段 IP 来自当地宽带运营商，在平台的检测里更像普通家庭用户。双 ISP 指服务器同时带有两个运营商的认证属性，检测工具里呈现家宽特征。三者叠加的"双 ISP 住宅原生 IP"是 TikTok 直播里最稳的一类。

原生 IP 不等于家宽 IP，这点在 WePC 的套餐页上就能看出来。英国 10.90 那条写的是"英国原生 IPv4，非家宽 IP"，新加坡 16.90 写的是"原生 IDC IPv4"，德国、台湾、越南、加拿大只标"原生 IP"没标家宽。这些便宜的线路 IP 归属地是对的，但段属性仍是机房。跑 TikTok 发视频可能没问题，主力直播号放上去，风控概率和家宽段不是一个量级。

下单前值得做一步核验：拿到机器后用 IP 归属查询工具看一下 ASN 和用途标签，是否显示为住宅/家宽。商家在说明里也提示过，具体属性以实测为准。

## 流量、内存和那几个容易被忽略的限制

流量不是瓶颈。这些套餐普遍给 1TB 到 2TB，标注为双向计费。按 1080P 推流 3Mbps 计算，一小时大约消耗 1.35GB，单账号每天播 4 小时、一个月 120 小时，也就 160GB 上下，离 2TB 差得很远。带宽同理，TikTok 标清直播需要 2–3Mbps 上行，1080P 建议 5Mbps 以上，WePC 最低的 50Mbps（日本优化线、越南）对单个直播间都够。

真正会卡住你的是内存。全系套餐清一色 512MB 起，最高的日本优化线也只有 786MB。这个配置的定位是网络出口，跑代理、做推流跳板没问题；想在上面装 Windows 远程桌面、跑剪辑或本地推流软件，512MB 是不够的，这类需求要另找高配 VPS 或 VDS。

还有两条写在说明里、但很容易被忽略的：

- **不承诺流媒体解锁**。产品定位是 TikTok 使用，Netflix、Gemini 这类能不能解锁看运气。第三方测评里，越南节点解不了 TikTok 和 Gemini，日本节点能解 TikTok、ChatGPT、Claude。
- **不承诺免费更换被中国大陆屏蔽的 IP**。使用期间 IP 被墙，换 IP 可能要另外付费，这点对长期跑号的成本有影响。

## 常见问题

**机房 IP 能不能做 TikTok 直播？**
能推流，但被判定为数据中心 IP 的概率高，表现为限流、播放量归零、画质被压。WePC 自己也卖 IDC 套餐（英国 10.90、新加坡 16.90、德国 10.90），价格便宜一半，适合发视频和养号，主力直播号建议还是家宽段。

**一台 VPS 能跑几个 TikTok 账号？**
一个直播账号配一个独立 IP，最多再带两三个养号账号。多账号共用一个 IP，关联风控的概率明显上升。

**直播需要多大带宽？**
标清 2–3Mbps，1080P 建议 5Mbps 以上。WePC 最低 50Mbps 的套餐对单直播间完全够，卡顿通常来自回国路由而不是带宽。

**"建议中转"到底要不要买中转？**
看你所在地区和运营商。韩国线电信移动直连、联通绕路；新加坡线移动可直连、电信必须中转；西班牙线官网直接写"必须加中转才能正常"。不确定就先买最短周期，用推流软件测十分钟，丢包和抖动比任何描述都准。

**续费会不会涨？**
列表页显示的是月付起价，长周期价格和续费价以结算页为准。下单前把计费周期切到年付看一眼总价，再决定按月还是按年。
